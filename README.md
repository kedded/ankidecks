# Recall

Anki-style flashcards in the browser. Import an Anki `.apkg`, study offline, nothing leaves the device.

**Deploy (GitHub Pages):** upload all files into one repo folder, flat, no subfolders. Delete the old `engine.js`, `app.js` and `sw.js` if present.
On iPhone: Safari -> Share -> Add to Home Screen. Settings shows the running version.

**Supports:** latest and legacy `.apkg`; basic, reversed, cloze and type-answer cards; audio, images, card CSS; nested decks; learning steps, daily limits, undo, streak.
**Not supported:** AnkiWeb sync, review-history import, JavaScript inside card templates (blocked by design).
